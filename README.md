# Pertemuan 8
Kodingan ini berisi logic tentang Queue:
- Variabel items, yang memegang seluruh element

- Function enqueue, yaitu function untuk memasukkan sebuah element ke dalam queue, lalu menampilkan pesan ke layar

- Function dequeue, yaitu function untuk mengeluarkan element dari queue, kalau sudah tidak ada element ya berarti logicnya tidak akan jalan. Setelah dikeluarkan, akan ada pesan yang ditampilkan di layar. Function tersebut bertipe fungsi, bukan prosedur, yang mana artinya element yang dihapus value nya masih sempat bisa diakses lagi.

- Bool get isEmpty, ya mengembalikan value isEmpty dari list items

- Function display, yaitu menampilkan keseluruhan isi queue

- Function main, tempat masuknya sebuah program dart, sama seperti bahasa pemrograman lain.
